1

问题PROBLEM

  • 身体技能（拳击 / 舞蹈 / 太极 / 羽毛球 / 健身）几乎无法用语言学会：「肩膀放松一点」到底多少？「重心往左」往哪？「手腕旋转」怎么转？
  • 视频教学是单向、第三人称的——你看得到教练，却看不到「自己」错在哪。
  • 私教昂贵、稀缺，反馈主观、不可量化、不可回放。
现有替代：YouTube / 短视频教程、健身私教、镜子、AI 语音纠错 App
4

解决方案SOLUTION

  • 观察：摄像头实时提取你的骨骼 → 关节 → 重心 → 速度 → 轨迹。
  • 成为你：G1 物理复刻你刚才的动作，让你第一次从第三人称看见自己的身体。
  • 对比：你的动作 → 正确动作 → 差异高亮，并给出量化评分。
  • 修正：G1 示范「你身体范围内最适合你」的动作，你再做，实时反馈进步。
3

独特价值主张UNIQUE VALUE PROPOSITION

机器人不是替你运动，而是教会你的身体。
一个会「成为你」的身体镜子：实时读懂你的骨骼与重心，复现你的动作，展示 你的动作 → 正确动作 → 差异，并给出适合你身体的修正。最终获得能力的是你，不是机器人。
高层概念：身体技能版的「随身私教 / Mirror」——Human Capability Loop，而非 Robot Task Loop。
8

门槛优势UNFAIR ADVANTAGE

  • G1 的身体本身就是产品：能物理复现人体动作，视频 / AR / 语音 AI 都做不到。
  • 「成为你」的第三人称镜像体验，难以被复制。
  • 越用越懂你的身体能力边界（个性化、持续学习）。
  • 可量化的身体技能评分体系 → 数据壁垒。

# Mirror · 镜身 — 产品文档（PRD）

**产品代号**：Mirror · 镜身（Embodied Motion Coach）
**一句话定位**：一个会「成为你」的身体镜子——人形机器人以第三人称复刻你的动作、高亮你的错误、演变为正确姿态，最终教会你的身体。
**Slogan**：机器人不是替你运动，而是教会你的身体。The robot doesn't move for you — it teaches your body.
**背景**：VentureD Hackathon 2026 · 杭州 · Track 02 Physical AI 具身智能（Unitree G1）
**文档状态**：v1.0（基于 Lean Canvas 与 Demo Deck 成文）

---

## 1. 产品概述

Mirror · 镜身把人形机器人从「代替人类干活」（Robot Task Loop）转向「教会人类身体」（Human Capability Loop）。

用户站在机器人面前做一个动作，机器人依次完成四件事：

1. **观察（Observe）**：实时提取用户的骨骼、关节、重心、速度与轨迹；
2. **成为你（Become You）**：物理复刻用户刚才的动作，让用户第一次从第三人称看见「自己的身体」；
3. **对比（Compare）**：将用户动作与标准动作做差异高亮，给出量化评分；
4. **修正（Correct）**：机器人示范「在用户身体能力范围内最适合的修正动作」，用户再做，实时反馈进步。

获得能力的是**用户**，不是机器人。

## 2. 问题与洞察

### 2.1 三个核心痛点

| 痛点 | 说明 |
| --- | --- |
| 身体技能无法用语言学会 | 「肩膀放松一点」到底放松多少？「重心往左」到底往哪？「手腕旋转」到底怎么旋？ |
| 视频教学是单向第三人称 | 用户看得到教练，却永远看不到「自己」错在哪。 |
| 私教昂贵、稀缺、不可回放 | 反馈主观、不可量化，且不是每个人约得起、请得起。 |

**现有替代方案**：YouTube / 短视频教程、健身私教、镜子、AI 语音纠错 App——均未解决根本问题。

### 2.2 底层洞察：本体感觉鸿沟（Proprioceptive Gap）

运动科学研究表明：看 2D 屏幕或听语音指令，很难纠正本体感觉偏差；只有从第三人称视角看到「与自己同比例、同物理空间」的实物示范，才能高效激活大脑的镜像神经元系统（Mirror Neuron System）。

- 屏幕上的红框与评分：作用于**认知层**，用户「知道」错了，但身体「不知道」怎么改。
- 机器人物理复刻：作用于**本体感觉层**，用户看到的是自己在三维空间中的真实姿态。

**产品本质**：填补「本体感觉回看」这条缺失的反馈通道，而不是做一个更好的评分 UI。

## 3. 市场演进与机会切口

| 阶段 | 代表产品 | 做到了什么 | 瓶颈（我们的机会） |
| --- | --- | --- | --- |
| Mirror 1.0（屏幕时代） | FITURE 魔镜、Lululemon Mirror、Tonal | 商业化成熟；2D/3D 骨骼点 + 屏幕画框提醒 | 无法提供物理实体的三维轨迹示范；反馈停留在打分与红框，无法唤起空间本体感觉 |
| VR / 遥操作 2.0 | Open-Television、DexCap、AnyTeleop | 人体到机械臂/人形机器人的低延迟遥操作 | 止步于「人控制机器人干活」（Robot Task Loop），未形成「机器人引导人」（Human Capability Loop） |
| 人形机器人 3.0 | 宇树 G1/H1/H2、智元、傅利叶 | 高自由度，能演示太极、舞蹈、武术 | 大多作为「表演者」或「劳力」，缺乏针对个人动作的实时捕获、错误动作同化与纠错闭环 |
| **镜身 3.5（本产品）** | **Mirror · 镜身** | **第三人称躯体复刻（Mistake Mirroring）+ 动态姿态演变（Motion Morphing）** | 将两者结合为商业产品，尚无大规模商业化先例——蓝海切口 |

### 3.1 理论与技术基石（学术支撑）

- **Human-to-Humanoid Retargeting**：NMR / IKMR 等端到端动作重定向研究，解决从人体 SMPL 3D 骨骼到人形机器人自由度的实时映射，并保证无自碰撞、符合动力学约束。
- **H2O（Human-to-Humanoid）**：利用强化学习将 RGB 摄像头捕捉的人体姿态实时重定向到人形机器人全身控制器。
- **AI Motion Coaching**：CoachMe / PoseForge 等框架对比「学员轨迹」与「专家轨迹」的生物力学差异（重心 Lean、关节角、双脚间距 Feet Gap），自动生成精准差值反馈。
- **镜像神经元与本体感觉理论**：支撑「物理实体第三人称示范」优于「屏幕/语音反馈」的产品假设。

## 4. 独特价值主张（UVP）

> 一个会「成为你」的身体镜子：实时读懂你的骨骼与重心，复现你的动作，展示 你的动作 → 正确动作 → 差异，并给出适合你身体的修正。最终获得能力的是**你**，不是机器人。

**Human Capability Loop**：人不会 → Robot observes → Robot understands → Robot demonstrates → Human learns → 人会了。

与 Robot Task Loop 的本质差异：任务完成后，能力沉淀在**人**身上——这是「教学产品」而非「服务产品」，因此具备课程式的复购与订阅属性，而非一次性替代劳动的价值。

## 5. 目标用户与场景

### 5.1 客户细分

| 层级 | 人群 | 场景 |
| --- | --- | --- |
| C 端（早期用户） | 自学健身 / 搏击武术 / 舞蹈爱好者 | 约不到、请不起私教，却想「学对动作」 |
| C 端（延展） | 太极 / 瑜伽 / 羽毛球 / 网球等身体技能学习者 | 动作准确性决定进阶上限 |
| B 端（付费先行） | 健身房、道馆、舞蹈室 | 差异化获客、课程增值、非高峰时段变现 |
| B 端（延展） | 康复机构、体育院校 | 动作量化评估、教学标准化 |

### 5.2 典型用户旅程（单次训练 15 分钟）

1. 用户选择课程（如「太极·起势纠错」），站在 G1 前 2–3 米处；
2. 跟随提示做一遍动作（约 30 秒），机器人静立观察；
3. 机器人说「我学一下刚才的你」——复刻用户动作（第三人称回看，多数用户第一次看到自己的动作形态）；
4. 屏幕出现双骨架对比：重心偏右、左肩抬高等差异高亮 + 量化分；
5. 机器人从「用户的错误姿态」渐变演化为「正确姿态」（Motion Morphing），可分段慢放；
6. 用户二次尝试，屏幕实时输出轨迹重合度上升曲线（如 Balance 61 → 84）；
7. 结束生成 session 报告与进步曲线，纳入个人身体档案。

## 6. 功能设计

### 6.1 核心体验四步（产品主循环）

**观察 → 成为你 → 对比 → 修正**（详见第 1 节）。Demo 层面表现为三阶段：

- 阶段 1：G1 1:1 镜像复刻用户动作 A（让用户看到自己的错误）；
- 阶段 2：G1 从动作 A 渐变插值至最佳修正姿态 B（姿态演变）；
- 阶段 3：用户二次尝试 → 屏幕输出轨迹重合度上升曲线（闭环完成）。

### 6.2 功能列表与优先级

| 模块 | 功能 | 优先级 | 验收标准（P0） |
| --- | --- | --- | --- |
| 感知 | 单目/深度相机人体 3D 骨骼与重心提取 | P0 | 30fps 以上；关节位置误差可支撑差异计算 |
| 镜像复刻 | Mistake Mirroring：用户动作物理复刻回放 | P0 | 单个 10 秒动作可稳定复刻，无自碰撞、不摔倒 |
| 差异引擎 | 学员 vs 标准动作生物力学差异高亮 | P0 | 输出 ≥3 类量化差异（重心/关节角/双脚间距） |
| 姿态演变 | Motion Morphing：错误 → 正确渐变示范 | P0 | 渐变过程平滑，可暂停/慢放/分段 |
| 评分系统 | 轨迹重合度评分 + 单次进步幅度 | P0 | 两次尝试可对比，输出提升数值（如 61→84） |
| 课程内容 | 标准动作库（首批：太极 8 式 / 搏击基础 5 式） | P1 | 每式含标准轨迹 + 差异特征配置 |
| 交互 | 语音提示 + 屏幕双骨架对比 UI | P1 | 全流程无鼠标操作 |
| 场馆端 | 多用户档案、排课、运营看板 | P2 | 支持 10 名用户档案隔离 |
| 个性化 | 用户身体能力边界建模（越用越懂你） | P2 | 修正建议随历史数据个性化 |

### 6.3 明确不做（Non-Goals，v1 阶段）

- 不做实时遥操作（人控机器人干活）；
- 不做全身接触式纠正（机器人不触碰用户）；
- 不做开放技能（首发封闭技能库，保证标准轨迹质量）；
- 不做家用版（首发场馆场景，规避安全与成本压力）。

## 7. 关键指标

| 指标 | 定义 | 目标（Pilot 阶段） |
| --- | --- | --- |
| **North Star**：单次训练动作改进幅度 | 同一 session 内评分提升（如 Balance 61→84） | 单次提升 ≥15 分 |
| 单次时长 | 用户与机器人单次交互时长 | ≥12 分钟 |
| 周训练频次 | 活跃用户每周使用次数 | ≥2 次 |
| 技能进步留存 | 4 周后仍在使用的用户比例 | ≥40% |
| 场馆复购率 | B 端续租/续约比例 | ≥70% |
| 传播系数 | 「看机器人变成我」短视频自发传播 | 单场馆月均 ≥3 条 UGC |

## 8. 商业模式

| 收入线 | 形式 | 说明 |
| --- | --- | --- |
| 场馆 RaaS | 按台月租 | 健身房/道馆/舞蹈室租赁，机器人即服务；B 端现金流先行 |
| 个人订阅 | 按次或包月 | 一台顶一个「永远在场」的私教；复用场馆设备 |
| 内容授权 | 动作标准库 / 课程授权 | 向硬件厂商与场馆输出「正确动作」标准库 |
| IP 合作 | 运动/健身品牌、赛事 | 「机器人教人」的内容天然具备传播性 |

**单位经济（假设，待 Pilot 验证）**：单台 G1 硬件 + 部署成本摊销、场馆月租定价对标 0.3–0.5 名私教成本、回本周期目标 ≤12 个月。核心逻辑：教学产品具备课程复购属性，边际内容成本递减。

## 9. 竞争与护城河

### 9.1 竞品对照

| 维度 | 屏幕健身镜 | VR/遥操作 | 人形表演 | **镜身** |
| --- | --- | --- | --- | --- |
| 物理三维示范 | ✗ | 虚拟 | ✓（非个性化） | ✓（复刻你） |
| 看见自己的错误 | ✗ | ✗ | ✗ | ✓（第三人称回看） |
| 量化差异与修正闭环 | 部分 | ✗ | ✗ | ✓ |
| 用户能力沉淀 | 弱 | ✗ | ✗ | ✓ |

### 9.2 护城河（别人抄得走 Demo，抄不走这三样）

1. **「成为你」的镜像体验**：身体才能镜像身体。物理复现 + 第三人称回看，视频 / AR 结构上做不到；
2. **越用越懂你的身体**：用户身体能力边界的个性化模型，持续学习、不可迁移；
3. **可量化的身体技能评分体系**：数据壁垒——评分标准与进步档案随用户规模累积。

叠加生态卡位：绑定 Unitree 硬件生态（G1 及后续机型），先发建立「机器人教练」品类认知。

## 10. 风险与应对

| 风险 | 等级 | 应对 |
| --- | --- | --- |
| 人机安全（机器人近距离演示） | 高 | 低速保守增益、距离围栏、急停冗余；首发封闭动作集 |
| 硬件成本高 | 高 | B 端 RaaS 分摊；紧盯 G1 降价曲线与租赁市场 |
| 标准动作库内容生产慢 | 中 | 冷启动用 G1 内置动作（Mimic 动作库）+ 教练采集管线 |
| 算法误判（复刻失真 / 差异错误） | 中 | 差异引擎输出置信度；低置信回退为「仅评分不高亮」 |
| 动作数据隐私 | 中 | 骨骼数据本地处理、匿名化存档、明示授权 |
| 「新奇感衰减」 | 中 | 以「单次可量化的进步」为留存钩子，而非猎奇体验 |
